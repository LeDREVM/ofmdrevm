Workflow général

Créer le personnage (Soul ID / Character). Sur Higgsfield, crée un personnage à partir de N'Aset OFM – Divine Maasaï.jpeg (ton image de référence). C'est lui qui garantit le même visage sur les 10 clips.
Générer la keyframe de chaque shot en image (Popcorn / Image Mode) avec le personnage sélectionné + le Prompt Image du shot. Vérifie palette et cadrage avant d'animer.
Animer en image-to-video avec le Prompt Vidéo du shot + le preset caméra indiqué. Un prompt = une tâche : le cadrage vit dans l'image, le mouvement vit dans la vidéo.
Enchaîner les clips d'une même scène avec l'extraction de frame : exporte la dernière frame du clip N et utilise-la comme image de départ du clip N+1. Continuité garantie sur les dolly longs (Scène 2).
Monter dans Premiere Pro : séquence 24 fps, conformer les clips, grade Filmic contraste moyen-fort, cut noir final à 95 s. Upscale 4K si besoin avant l'étalonnage.
⚠️ Règle d'or Higgsfield : prompts courts et directs. Une seule instruction caméra par clip. Esthétique OFM : sacré + minimalisme — effets subtils, jamais excessifs.

Blocs réutilisables

Identité — à coller dans chaque prompt imageN'Aset, a majestic young African priestess, tall slender athletic silhouette, deep brown skin, black cornrow braids with red beads, wide multicolored Maasai beaded collar, crimson shuka drape over one shoulder, flowing ivory sacred cloth, gold Egyptian arm cuffs and wide gold bracelet, subtle dark kohl eyeliner, sovereign regal presence.
Style — à coller à la fin de chaque prompt imageCinematic still, vast golden savanna, warm golden haze, sacred minimalism, filmic color grade, medium-high contrast, photorealistic, 16:9.
À éviter (champ négatif ou fin de prompt)No modern clothing, no phone, no jeans, no text, no watermark, no excessive glow, no camera shake, no extra characters.

L'image de référence contient un pull et un jean modernes : le bloc « À éviter » est indispensable pour que Soul ID ne garde que le visage, les tresses, le collier et les drapés.
