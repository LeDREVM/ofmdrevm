## Formats Fichiers Pipeline

| Extension | Description | Usage |
|-----------|-------------|-------|
| `.blend` | Fichier Blender natif | Modèles, scènes, animations |
| `.fbx` | Format 3D universel | Export Blender → UE5 |
| `.abc` | Alembic — animation baked | Cloth, particules Blender → AE |
| `.exr` | OpenEXR HDR | Rendu Cycles → AE (16/32bit) |
| `.png` | Séquence rendu | Frame par frame |
| `.mov` | Vidéo ProRes | Export intermédiaire |
| `.mp4` | H.264/H.265 | Livraison finale |
| `.usdc` | USD — Universal Scene | Échange UE5 ↔ Blender |
| `.groom` | Asset cheveux UE5 | Importé depuis Blender |
| `.uasset` | Asset UE5 compilé | Matériaux, textures, BP |
